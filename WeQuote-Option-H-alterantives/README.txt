WEQUOTE — OPTION H PACKAGE

1. Extract the entire ZIP.
2. Open OPEN-THIS.html in a browser.
3. Choose the complete Option H prototype, step-by-step handoff, or the latest No Deal popup layout.

The complete prototype is a portable snapshot of the current Option H sources.
The separate No Deal layout proposes the friendlier popup wording and is also included in the interactive handoff.
PDF/Word documents and reference screenshots are earlier handoff/review snapshots.

The demos are local and reset on refresh. CRM writes, email, payment, live PDF generation and backend persistence are not connected. The complete prototype uses example URLs; live CRM Deal pages are outside this package.

All visual assets needed by the HTML demos are embedded. Keep the folders together for links from OPEN-THIS.html.
Package verification covers ZIP integrity, byte equality, local links, embedded assets and JavaScript syntax; it does not establish rendered browser or production behavior.
