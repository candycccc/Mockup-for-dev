# Warehouse screenflow

Open **index.html** to view the Stocked Items screenflow and UI/UX Suggestions.

## Upload

Extract the ZIP and upload all its contents together, preserving the screenshot
folder. The only HTML entry point is `index.html`. Keep both CSS files, the
JavaScript file and `stocked-items-screenflow-assets` beside it.

This is a static website suitable for GitHub Pages. No build command, package
installation, application server or database is needed. Uploading the files to
a repository does not by itself enable website publishing.

## Contents

- Current Demo app screenflow with 50 captured screenshots and screenshot zoom.
- Four UI/UX Suggestions with interactive proposed layouts.
- Side-by-side status-menu and direct-listing options for Goods In / Goods Out.

The proposed layouts are review examples. They do not submit warehouse
transactions. The original Demo app and its 3D warehouse are not included.
