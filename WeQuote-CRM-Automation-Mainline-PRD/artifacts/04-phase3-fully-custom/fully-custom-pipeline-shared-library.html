Starts when

The same event picker appears in every Custom Stage.

Stage and Deal

  • A Deal is created
  • A Deal enters or leaves this Stage
  • A Deal moves from a selected Stage
  • A Deal stays in this Stage for a set time
  • Owner, Watcher, Label or Interest changes
  • Value, Margin or Expected Close Date changes

Activities, files and time

  • Next Action or Note follow-up changes
  • Meeting or Site Visit status changes
  • A file is uploaded, removed or received
  • No activity for a set time
  • A selected date or time is reached

Optional Quote events

  • Quote created, edited, sent, viewed, accepted or expiring
  • Shown only when related Quote data is available

Rules

The same condition library appears in every Custom Stage.

Stage and Deal data

  • Deal is still in this Stage
  • Deal came from a selected Stage
  • Deal stayed here for a set time
  • Owner, Watcher, Label or Interest matches
  • Value, Margin, Company or Expected Close matches
  • Automation has or has not run before

Work and evidence

  • Next Action or recent Activity exists
  • Meeting or Site Visit has a selected status
  • Open Note follow-up exists
  • Required file exists or is missing
  • Open file request exists

Paths and optional Quote data

  • Combine Rules with AND or OR
  • Each result creates a Yes and No path
  • Quote status, viewed state, expiry or viability when available

Actions

The same Action library appears in every Custom Stage.

Deal work

  • Assign a specific Deal Owner
  • Set or clear the Deal Next Action
  • Add or remove a Deal Watcher
  • Add or remove a Deal Label
  • Add or remove an Interest
  • Create a Note
  • Schedule a Meeting or Site Visit

Files, dates and communication

  • Request a file or attach a file
  • Set the Expected Close Date
  • Send an internal notification
  • Optional: create a related Quote or add a Quote Label

Flow control

  • Move Deal to another Stage in this Pipeline
  • End the Automation path safely
