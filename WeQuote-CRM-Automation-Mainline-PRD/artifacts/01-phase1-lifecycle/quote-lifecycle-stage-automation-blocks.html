This shows the Automation choices inside the existing Quote Lifecycle. It does not add or change Pipeline Stages.

Protected lifecycle ruleAutomations may react to trusted Quote events and update CRM work, but they cannot rename, remove, reorder or fake a protected lifecycle milestone. The Quote event—not a generic Move Deal Action—changes the protected Stage.
1
Protected Stage

Qualified

The Deal is qualified, but no related Quote has been created yet.

Starts when

  • A qualified Deal is created
  • The Deal enters Qualified
  • The Deal Owner, Watcher, Label or Interest changes
  • Deal Value or Expected Close Date changes
  • A Next Action or Note follow-up becomes due
  • A Meeting / Site Visit changes
  • A requested file is received
  • No activity for a set time

Rules

  • The Deal is still Qualified
  • No related Quote exists
  • The Owner or Next Action is missing
  • Required customer or site information is complete
  • A required file exists or is missing
  • Value, Margin, Company, Label or Interest matches
  • This Automation has or has not run before

Actions

  • Assign the Deal Owner
  • Set or clear the Next Action
  • Add or remove a Watcher, Label or Interest
  • Create a Note or schedule a Meeting / Site Visit
  • Request or attach a file
  • Set the Expected Close Date
  • Send an internal notification
  • Create the first related Quote, when allowed
Lifecycle event that moves the DealThe first related Quote is created → In Progress.
CheckpointSupported internal readiness checks may be required before the first Quote is created.
2
Protected Stage

In Progress

One or more related Quotes are being prepared, priced or edited.

Starts when

  • The Deal enters In Progress
  • The first or another related Quote is created
  • A Quote is edited
  • Products, pricing or Scope of Work changes
  • A Quote or Deal file is added
  • A Next Action or Note follow-up becomes due
  • A Meeting / Site Visit changes
  • No activity for a set time

Rules

  • The Deal is still In Progress
  • A related Quote is Draft and viable
  • Products, pricing or Scope of Work is complete
  • Quote Review is enabled or disabled
  • A reviewer, technical file or build Note is missing
  • No open Next Action or recent Activity exists
  • Value, Margin, discount, Label or Interest matches

Actions

  • Create a build or review Note
  • Set or clear the Next Action
  • Assign the Deal Owner or add a reviewer as Watcher
  • Request or attach a technical file
  • Add or remove a Deal Label or Interest
  • Add a Quote Label
  • Set the Expected Close Date
  • Send an internal notification
Lifecycle event that moves the DealSubmit for Review → In Review. If Review is off, issue the Quote → Sent.
CheckpointSelected internal work may be required before Submit for Review or Send.
3
Protected Stage · conditional

In Review

The Quote has been submitted for internal review.

Starts when

  • The Deal enters In Review
  • The Quote is submitted for internal review
  • Quote Review changes
  • The reviewer or Deal Owner changes
  • A review Note changes or becomes due
  • A technical file is uploaded
  • A requested file is received
  • A Next Action becomes due

Rules

  • The Quote is still In Review
  • Quote Review is enabled
  • An open technical review Note exists
  • A required reviewer or approval is missing
  • A required technical file exists or is missing
  • All review checks are complete
  • Value or discount needs additional approval
  • No open Next Action exists

Actions

  • Create a technical review Note
  • Set the Next Action
  • Assign the Deal Owner or add a reviewer as Watcher
  • Request or attach a technical file
  • Add or remove a Deal Label
  • Add a Quote Label
  • Send an internal notification
  • Cannot pass or reject the Quote as a generic Automation Action
Lifecycle event that moves the DealReviewer passes the Quote → Passed Review. Changes requested → In Progress.
CheckpointTechnical Notes, files and approvals may be required before the reviewer passes the Quote.
4
Protected Stage · conditional

Passed Review

The Quote has passed internal review and is waiting to be issued.

Starts when

  • The Deal enters Passed Review
  • The Quote passes internal review
  • The Quote is edited after review
  • A final file is added or removed
  • A Next Action or Note follow-up becomes due
  • The Expected Close Date is approaching

Rules

  • The Quote is still in Passed Review
  • The Quote is viable
  • Customer-facing content is complete
  • Recipient details and expiry date are complete
  • Commercial approval is complete
  • A final document exists or is missing
  • Value, Margin or discount matches an approval rule

Actions

  • Create a ready-to-send Note
  • Set the customer follow-up Next Action
  • Schedule a Meeting
  • Add an approver as Watcher
  • Add or remove a Deal Label or Interest
  • Attach a final document
  • Add a Quote Label
  • Set the Expected Close Date
  • Send an internal notification
Lifecycle event that moves the DealThe Quote is issued to the customer → Sent.
CheckpointSelected final commercial checks may be required before Send.
5
Protected Stage

Sent

At least one viable Quote has been issued and awaits the customer outcome.

Starts when

  • The Deal enters Sent
  • A Quote is sent
  • The customer views a Quote
  • A Quote expiry date is approaching
  • A Quote is accepted, cancelled or expires
  • A Next Action or Note follow-up becomes due
  • No activity for a set time
  • A customer or commercial file is added

Rules

  • A Quote is still Sent, viable and not accepted
  • Number of related Quotes viewed by the customer
  • No accepted Quote exists
  • No recent Activity or open Next Action exists
  • The latest Quote expiry date has passed
  • No viable related Quote remains
  • All related Quotes are cancelled
  • Value, Label, Interest or Expected Close matches

Actions

  • Set or clear the customer follow-up Next Action
  • Create a Note or schedule a Meeting
  • Assign the Deal Owner or add a Watcher
  • Add or remove a Deal Label or Interest
  • Request or attach a file
  • Set the Expected Close Date
  • Send an internal notification
  • Cannot block a customer view, acceptance or protected outcome
Lifecycle event that moves the DealAccepted Quote → Won. No viable Quote remains → Lost. All Quotes cancelled → Archived, not a Stage.
CheckpointTrusted customer events and protected outcomes cannot be held by an unfinished internal task.
6
Protected outcome

Won

A related Quote has been accepted. Use this Stage for Sales completion and handover Automation.

Starts when

  • The Deal enters Won
  • A related Quote is accepted
  • The winning Quote or Deal Owner changes
  • A handover Next Action or Note changes
  • A final or handover file is uploaded
  • A Meeting / Site Visit changes

Rules

  • The Deal is still Won
  • An accepted Quote exists
  • The winning Quote matches selected criteria
  • A handover Owner or Next Action exists or is missing
  • A required handover file exists or is missing
  • Value, Company, Label or Interest matches

Actions

  • Clear or set the Deal Next Action
  • Assign a handover Owner
  • Add or remove a Watcher, Label or Interest
  • Create a handover Note
  • Schedule a Meeting or Site Visit
  • Request or attach a handover file
  • Send an internal notification
  • End the Automation path safely
Protected outcomeWon is final in the Sales Pipeline. Delivery, Billing or Project setup should start from a Won Automation.
Not availableA generic Automation cannot redefine Won or move the Deal to another protected outcome.
7
Protected outcome

Lost

No viable related Quote remains and the Sales opportunity has ended.

Starts when

  • The Deal enters Lost
  • No viable related Quote remains
  • A Quote is rejected, expires or becomes non-viable
  • A loss reason, Label or Owner changes
  • A final Note or file is added
  • A selected re-engagement date is reached

Rules

  • The Deal is still Lost
  • No accepted Quote exists
  • No viable related Quote remains
  • A loss reason or selected Label exists
  • No open Next Action remains
  • Owner, Company, Value or Interest matches
  • A future follow-up date exists

Actions

  • Clear or set a future Deal Next Action
  • Add or remove an outcome Label
  • Remove a Watcher or assign a follow-up Owner
  • Create a closing or re-engagement Note
  • Schedule a future Meeting
  • Attach the final file
  • Send an internal notification
  • End the Automation path safely
Protected outcomeLost is final in the Sales Pipeline. A future opportunity should use a deliberate new or reopened Sales flow.
Not availableA generic Automation cannot redefine Lost or silently convert it into Won.
Shared CRM ActionsOwner, Next Action, Watcher, Label, Interest, Note, Meeting, Site Visit, Files, Expected Close Date and notifications remain available where the data exists.
Stage-first filteringThe Builder only shows start events and Quote Rules that can happen in the selected protected Stage.
Trusted lifecycle transitionsQuote creation, review outcome, sending, customer acceptance and viability determine the protected Stage.
