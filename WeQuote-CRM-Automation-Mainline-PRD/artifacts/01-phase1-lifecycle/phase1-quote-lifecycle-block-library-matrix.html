WeQuote CRM Phase 1 · Fixed Quote lifecycle only

Block Library by Quote Lifecycle Stage

Start from scratch uses one Global Block Catalogue. Every Stage receives the same Shared Core blocks, then adds only the Quote-specific Starts when and Rules that can genuinely happen in that Stage.

Phase 1 scope: Qualified → In Progress → In Review → Passed Review → Sent → Won / Lost. No Custom Stages.

Shared by all seven Stages

These Core block IDs, names and settings stay identical everywhere

Shared Core Starts when

  • Deal Owner changes
  • Deal Next Action changes or becomes due
  • Meeting / Site Visit changes
  • File added or requested file received
  • Deal inactivity
  • Expected Close Date approaching
  • Deal data changes

Shared Core Rules

  • Owner or Next Action missing
  • Required task or file missing
  • Meeting / Site Visit complete
  • Recent Activity exists
  • Label, Interest, Value or Company matches
  • Expected Close Date matches

Shared Core Actions

  • Assign Deal Owner
  • Set / Clear Deal Next Action
  • Create Note
  • Schedule Meeting / Site Visit
  • Add / Remove Watcher, Label or Interest
  • Request / Attach file
  • Set Expected Close Date
  • Send internal notification
