Multi Custom Stages in a Quote-connected Pipeline

One or many customer-defined Custom Stages may be inserted between protected Quote lifecycle Stages. Every inserted Custom Stage uses one identical Shared Core Automation library.

✓
Non-negotiable invariant: every Custom Stage receives the exact same Core block IDs. No Core block may be added, removed, renamed, hidden or disabled because the Stage is placed in a different lifecycle segment.
In scope A Quote-connected Pipeline with one or multiple Custom Stages inserted between protected lifecycle Stages.
Not this diagram A Fully Custom Pipeline. It has no protected Quote lifecycle result and must be documented separately.

One source of truth: Shared Core block library

Available options — not a saved Automation

Starts when

  • Deal enters this Custom Stage
  • Deal Owner changes
  • Deal Next Action changes or becomes due
  • Meeting / Site Visit changes
  • File is added or requested file is received
  • Deal inactivity or Expected Close approaches
  • Deal data changes

Rules

  • Deal is still in this Custom Stage
  • Owner or Next Action is missing
  • Required task or file is missing
  • Meeting / Site Visit is complete or incomplete
  • Recent Activity exists or does not exist
  • Label, Interest, Value or Company matches
  • Expected Close Date matches

Actions

  • Assign Deal Owner
  • Set / Clear Deal Next Action
  • Create Note
  • Schedule Meeting / Site Visit
  • Add / Remove Watcher, Label or Interest
  • Request / Attach file
  • Set Expected Close Date
  • Send internal notification
  • Move to a named Custom Stage
