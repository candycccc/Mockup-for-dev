Starts when

Deal enters this Stage · Owner or Next Action changes · Meeting, Site Visit or file changes · No activity · Expected Close is near.

Rules

Deal is still here · Owner, Next Action, task or file is missing · Activity exists · Deal details match.

Actions

Create Note · Schedule Meeting or Site Visit · Set Next Action · Request or attach file · Assign Owner · Update Watcher, Label or Interest · Notify · Move to a named Custom Stage.

Important:Quote events move the Deal into the next fixed Stage. A customer Automation cannot replace them with a normal “Move Deal” Action.
