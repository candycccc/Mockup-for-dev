What Changes Between the Five Lifecycle Gaps?

A Custom Stage placed after Qualified is not the same business moment as one placed after Sent — but both must open the same Shared Core Automation library.

What stays exactly the same

  • The complete Starts when, Rules and Actions block library.
  • Block names, IDs, configuration fields and validation.
  • Draft, Test, Publish and Active / Inactive behaviour.

What changes by placement

  • The Quote's current lifecycle state and available runtime data.
  • The protected event that moves the Deal to the next fixed Stage.
  • Flow Summary context and valid Custom Stage target values.

What the developer changes in the Editor UI

Workflow blocks

No placement filtering. Render the complete Shared Core block library every time.

Block settings

The block remains the same, but contextual values may differ — for example, valid named Custom Stage targets within the current segment.

Flow Summary

Show Pipeline, current Custom Stage, Company scope, lifecycle segment, current Quote context and the next protected system event.

Developer rule Placement selects lifecycle context metadata; it must never select a different Core block library. Recommended examples or templates may change, but permissions and available Core blocks do not.
