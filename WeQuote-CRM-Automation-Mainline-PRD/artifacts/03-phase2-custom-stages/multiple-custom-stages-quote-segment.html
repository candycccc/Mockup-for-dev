One lifecycle segment: Between Qualified and In Progress
What the user sees when opening A, X or BThe same complete Starts when, Rules and Actions menu appears in all three editors. “This Custom Stage” automatically displays the Stage currently being edited.

Starts when

Available in Custom A, Custom X and Custom B.

  • The Deal enters this Custom Stage
  • The Deal Owner changes
  • A Next Action becomes due, overdue or completed
  • A Meeting or Site Visit is scheduled, starts or completes
  • A file is uploaded or a requested file is received
  • The Deal has no activity for a set number of days
  • The Expected Close Date is approaching

Rules

Available in Custom A, Custom X and Custom B.

  • The Deal is still in this Custom Stage
  • No related Quote exists yet
  • The Owner or Next Action is missing
  • Site or customer information is incomplete
  • The Site Visit has not been completed
  • A required plan or file is missing
  • An open file request exists
  • Label, Interest, Value, Company or Expected Close matches

Actions

Available in Custom A, Custom X and Custom B.

  • Assign the Deal Owner
  • Set or clear the Next Action
  • Create a Note or schedule a Meeting / Site Visit
  • Add or remove a Watcher, Label or Interest
  • Request a file or attach a file to the Deal
  • Set the Expected Close Date
  • Create the first related Quote
  • Move to another Custom Stage in this same segment

Rules that keep the model understandable and safe

Same menu, separate setupA, X and B see the same available blocks, but changes made in one Stage do not change the other two.
Current Stage wording“Deal enters this Custom Stage” becomes A, X or B according to the editor currently open.
Custom-to-Custom movementMove Deal selects another Custom Stage inside the same lifecycle segment.
Protected boundaryCreating the first Quote moves the Deal to In Progress. Warn before skipping later Custom Stages; block the skip when a later Stage is Required.
