Automation block for every Custom Stage

The Stage names below are examples. Every Custom Stage uses the same complete option library, while the suggested choices change with the work happening at that Stage.

1
Example Custom Stage

New Opportunity

Capture and route a newly created Deal before discovery work starts.

Starts when

  • A Deal is created in this Pipeline
  • The Deal enters New Opportunity
  • The Deal Owner, Label or Interest changes
  • Deal Value or Expected Close Date changes
  • The Deal has no activity for a set number of days
  • A selected date or time is reached

Rules

  • The Deal is still in New Opportunity
  • The Owner is missing or matches a selected person
  • A Label or Interest is present or missing
  • Value, Margin, Company or Expected Close matches
  • No open Next Action or recent activity exists
  • This Automation has or has not run before

Actions

  • Assign a specific Deal Owner
  • Set or clear the Deal Next Action
  • Add or remove a Watcher, Label or Interest
  • Create a Note or internal notification
  • Request or attach a file
  • Move the Deal to Discovery or another Custom Stage
What moves the Deal forwardOnly a selected Move Deal Action or a manual move changes the Stage.
Required checkpointOptional. The customer can require an Owner, Next Action or selected data before moving forward.
2
Example Custom Stage

Discovery

Collect the customer need, qualify the opportunity and organise follow-up work.

Starts when

  • The Deal enters or leaves Discovery
  • A Next Action becomes due, overdue or completed
  • A Note follow-up becomes due or is completed
  • A Meeting is scheduled, starts, completes or is cancelled
  • A Label, Interest, Value or Expected Close Date changes
  • There has been no activity for a set number of days

Rules

  • The Deal came from a selected Stage
  • The Deal has stayed in Discovery for a set time
  • Required Interests or customer details are present
  • An open Next Action exists, is missing or is overdue
  • A recent Activity or completed Meeting exists
  • Value, Margin, Label, Company or Owner matches

Actions

  • Set the next customer follow-up Action
  • Create a Note or schedule a Meeting
  • Assign the Owner or add a Watcher
  • Add or remove a Deal Label or Interest
  • Set the Expected Close Date
  • Request a customer file
  • Move the Deal to Site Survey, Proposal or another Custom Stage
What moves the Deal forwardThe customer defines the readiness rule, then adds an explicit Move Deal Action.
Required checkpointOptional. For example: Interest selected and Discovery Meeting completed.
3
Example Custom Stage

Site Survey

Coordinate the visit and collect the files required before preparing a proposal.

Starts when

  • The Deal enters or leaves Site Survey
  • A Site Visit is scheduled, starts, completes or is cancelled
  • A file is uploaded or removed
  • A requested file is received
  • A Next Action or Note follow-up becomes due
  • The Deal stays here or has no activity for a set time

Rules

  • The Site Visit has a selected status
  • A required plan, photo or proof file exists or is missing
  • An open file request or technical Note exists
  • An Owner, Watcher or Next Action is missing
  • The Deal has stayed in this Stage for a set time
  • Value, Interest, Label or Company matches

Actions

  • Schedule or update a Site Visit
  • Request a file or attach a file to the Deal
  • Create a technical Note
  • Set or clear the Next Action
  • Assign the Owner or add a Watcher
  • Send an internal notification
  • Move the Deal to Proposal or another Custom Stage
What moves the Deal forwardA Rule can check that the visit and required files are complete before the Move Deal Action runs.
Required checkpointOptional. Missing files or an incomplete visit can hold the Automation path.
4
Example Custom Stage

Proposal

Prepare the commercial response, with or without related Quote data.

Starts when

  • The Deal enters or leaves Proposal
  • Deal Value, Margin or Expected Close Date changes
  • A proposal file is uploaded or removed
  • A Next Action or Note follow-up becomes due
  • The Expected Close Date is approaching
  • Optional: a related Quote is created, edited, sent, viewed or accepted

Rules

  • The Deal is still in Proposal
  • Value, Margin or approval threshold matches
  • A proposal file exists and required work is complete
  • No open Next Action or recent activity exists
  • Optional: Quote status, viewed status or expiry matches
  • Optional: an accepted or viable related Quote exists

Actions

  • Create a Note, Meeting or customer follow-up Action
  • Assign the Owner or add a Watcher
  • Add or remove a Label or Interest
  • Attach a proposal file
  • Set the Expected Close Date
  • Optional: create a related Quote or add a Quote Label
  • Move the Deal to Closed or another Custom Stage
What moves the Deal forwardQuote events never move a Fully Custom Pipeline by themselves; add a separate Move Deal Action.
Required checkpointOptional. Proposal, commercial approval or follow-up work can be required.
5
Example Custom Stage

Closed

A customer-defined ending Stage. It does not automatically mean Won or Lost.

Starts when

  • The Deal enters or leaves Closed
  • The Deal moves here from a selected Stage
  • The Owner, Label, Interest or outcome data changes
  • A final file is uploaded
  • A selected date or time is reached
  • Optional: a related Quote is accepted, cancelled or expires

Rules

  • The Deal is still in Closed
  • A selected outcome Label or reason exists
  • A final file, Note or completed Activity exists
  • No open Next Action or file request remains
  • Value, Company, Owner or Interest matches
  • Optional: an accepted Quote or no viable Quote remains

Actions

  • Clear the Deal Next Action
  • Add or remove an outcome Label
  • Remove a Watcher or assign a handover Owner
  • Create a closing or handover Note
  • Attach the final file
  • Send an internal notification
  • Move back to another Custom Stage, if the customer allows reopening
  • End the Automation path safely
What the Stage meansThe customer defines the outcome. WeQuote does not silently convert it into Won, Lost or Archived.
ReopeningAllowed only through a clearly configured manual move or Move Deal Action.
Safe Stage movesA Move Deal Action can only use a Stage in the same Pipeline. WeQuote warns about loops or repeated runs before publishing.
Required workA file request, Note or Next Action can be required. The Automation waits for completion before its next step.
No hidden lifecycleWeQuote does not assume Qualified, Sent, Won or Lost. The customer defines what every Stage means.
Pipeline with Quote Lifecycle · protected milestones with optional Custom StagesThe customer can add Custom Stages between protected milestones. They cannot rename, remove or reorder protected milestones, and an Automation cannot fake a Quote lifecycle event.

Options for every Custom Stage position

Each block below shows the full set of practical choices for a Custom Stage added at that point in the Quote lifecycle.

1
Custom Stage position

Between Qualified and In Progress

Use this section for discovery, site readiness and work that must happen before the first Quote.

Starts when

  • The Deal enters this Custom Stage
  • The Deal Owner changes
  • A Next Action becomes due, overdue or completed
  • A Meeting or Site Visit is scheduled, starts or completes
  • A file is uploaded or a requested file is received
  • The Deal has no activity for a set number of days
  • The Expected Close Date is approaching

Rules

  • The Deal is still in this Custom Stage
  • No related Quote exists yet
  • The Owner or Next Action is missing
  • Site or customer information is incomplete
  • The Site Visit has not been completed
  • A required plan or file is missing
  • An open file request exists
  • Label, Interest, Value, Company or Expected Close matches

Actions

  • Assign the Deal Owner
  • Set or clear the Next Action
  • Create a Note or schedule a Meeting / Site Visit
  • Add or remove a Watcher, Label or Interest
  • Request a file or attach a file to the Deal
  • Set the Expected Close Date
  • Create the first related Quote
  • Move to another Custom Stage in this same section
What moves the Deal forwardCreating the first related Quote moves the Deal to protected In Progress.
Required checkpoint allowedSelected work can be required before the first Quote is created.
2
Custom Stage position

Between In Progress and In Review / Sent

Use this section while the Quote is being built, priced and prepared for review or sending.

Starts when

  • The Deal enters this Custom Stage
  • The first related Quote is created
  • A Quote is edited
  • Products, pricing or Scope of Work changes
  • A Quote or Deal file is added
  • A Note follow-up or Next Action becomes due
  • A Meeting / Site Visit changes
  • The Deal has no activity for a set number of days

Rules

  • The Quote is still Draft / In Progress
  • Pricing or Scope of Work is complete or incomplete
  • Quote Review is enabled or disabled
  • A technical file or reviewer is missing
  • An open build or technical Note exists
  • A required file is missing
  • No open Next Action or recent activity exists
  • Value, Margin, discount, Label or Interest matches

Actions

  • Create a build or review Note
  • Set or clear the Next Action
  • Assign the Deal Owner or add a reviewer as Watcher
  • Request or attach a technical file
  • Add or remove a Deal Label or Interest
  • Add a Quote Label
  • Set the Expected Close Date
  • Send an internal notification
  • Move to another Custom Stage in this same section
What moves the Deal forwardSubmit for Review moves it to In Review. If Review is off, sending the Quote moves it to Sent.
Required checkpoint allowedSelected work can be required before Submit for Review or Send.
3
Custom Stage position

Between In Review and Passed Review

Use this section for technical review work, missing information and approval follow-up.

Starts when

  • The Deal enters this Custom Stage
  • The Quote is submitted for review
  • The reviewer or Deal Owner changes
  • A review Note changes or becomes due
  • A technical file is uploaded
  • A requested file is received
  • A Next Action becomes due

Rules

  • The Quote is still In Review
  • An open technical review Note exists
  • A required reviewer or approval is missing
  • A required technical file is missing
  • All review checks are complete
  • Value or discount needs additional approval
  • No open Next Action exists

Actions

  • Create a technical review Note
  • Set the Next Action
  • Assign the Deal Owner or add a reviewer as Watcher
  • Request or attach a technical file
  • Add or remove a Deal Label
  • Add a Quote Label
  • Send an internal notification
  • Move to another Custom Stage in this same section
  • Cannot approve the Quote as an Automation Action
What moves the Deal forwardA reviewer passes the Quote → Passed Review. Changes requested → In Progress.
Required checkpoint allowedSelected review work can be required before the reviewer passes the Quote.
4
Custom Stage position

Between Passed Review and Sent

Use this section for final commercial checks and customer-facing documents before sending.

Starts when

  • The Deal enters this Custom Stage
  • The Quote passes internal review
  • The Quote is edited after review
  • A final file is added
  • A Next Action or Note follow-up becomes due
  • The Expected Close Date is approaching

Rules

  • The Quote is still in Passed Review
  • The Quote is viable
  • Customer-facing content is complete
  • Recipient details and expiry date are complete
  • Commercial approval is complete
  • A final document is missing
  • Value, Margin or discount matches an approval rule

Actions

  • Create a ready-to-send Note
  • Set the customer follow-up Next Action
  • Schedule a Meeting
  • Add an approver as Watcher
  • Add or remove a Deal Label or Interest
  • Attach a final document
  • Add a Quote Label
  • Set the Expected Close Date
  • Send an internal notification
  • Move to another Custom Stage in this same section
What moves the Deal forwardIssuing the Quote to the customer moves the Deal to protected Sent.
Required checkpoint allowedSelected final checks can be required before the Quote is sent.
5
Custom Stage position

Between Sent and Won / Lost

Use this section for customer engagement, follow-up, expiry and commercial close-out.

Starts when

  • The Deal enters this Custom Stage
  • A Quote is sent
  • The customer views a Quote
  • A Quote expiry date is approaching
  • A Quote is accepted or cancelled
  • A Next Action or Note follow-up becomes due
  • The Deal has no activity for a set number of days
  • A customer or commercial file is added

Rules

  • A Quote is still Sent, viable and not accepted
  • Number of related Quotes viewed by the customer
  • No accepted Quote exists
  • No recent activity or open Next Action exists
  • The latest Quote expiry date has passed
  • No viable related Quote remains
  • All related Quotes are cancelled
  • Value, Label, Interest or Expected Close matches

Actions

  • Set or clear the customer follow-up Next Action
  • Create a Note or schedule a Meeting
  • Assign the Deal Owner or add a Watcher
  • Add or remove a Deal Label or Interest
  • Request or attach a file
  • Set the Expected Close Date
  • Send an internal notification
  • Move to another Custom Stage in this same section
  • Cannot block a customer view, acceptance or final outcome
What moves the Deal forwardAccepted Quote → Won. No viable Quote → Lost. All related Quotes cancelled → Archived, not a Stage.
Required checkpoint not allowedTrusted customer events and protected outcomes always continue.
No required checkpointWhen the protected Quote event happens, the Deal leaves the Custom Stage and moves to the correct protected milestone.
Required checkpoint setOnly an allowed internal event can wait. The UI shows the unfinished work and what must be completed.
Trusted customer eventA Quote view, customer acceptance, or the Won/Lost result can never be blocked by a Custom Stage or Automation.
